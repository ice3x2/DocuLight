# DocuLight 신문지 테마 디자인 결정

- 결정일: 2026-09-16
- 상태: 사용자 승인 · 시각 디자인 확정
- 승인 내용: “이 설계로 확정합니다. 이렇게 갑시다. 딱 신문지 테마 좋겠네요.”
- 승인 시안: [신문지 테마 HTML](./newspaper-theme.html)

## 디자인 적용 가이드

- [디자인 스타일 가이드](./newspaper-style-guide.md): 색상 토큰, 글꼴, 간격·모양, 화면 배치, 편집기, CSS 구성과 검증 기준.
- [입력폼과 공통 조작 규칙](./newspaper-forms.md): UX 전문가가 정리한 입력·버튼·선택기·모달·오류·포커스 규칙.
- [구현 핸드오프와 확정 결정](./newspaper-implementation-handoff.md): 위임된 다크 팔레트 결정, 이슈 #42~#77의 REQ/AC 매핑, 확대·PAT·테마 캐시 계약 및 구현 경계.

두 가이드는 승인 시안을 구체화한 후속 설계 문서다. 새 동작과 수용 기준은 구현 전에 관련 SRS에 반영한다.

## 결정

DocuLight의 시각 디자인은 신문지 테마로 진행한다. 회백색 종이 바탕, 짙은 인쇄 잉크색 텍스트, 절제된 잉크 블루 강조색을 사용한다. 양피지의 노란 기운보다 중립적인 회백색을 중심으로 한다. 종이 질감 이미지 없이 색상·글꼴·구분선으로 분위기를 표현한다.

UI 컴포넌트는 기존 Radix 기반과 shadcn/ui를 사용한다. 첨부 HTML은 사용자가 승인한 외관을 보존한 독립 정적 시안이며, shadcn/ui로 구현된 제품 화면은 아니다.

## 팔레트

| 역할 | 색상 |
| --- | --- |
| 앱 배경 | `#E9E7E2` |
| 문서 배경 | `#F5F4EF` |
| 사이드바 | `#DEDDD6` |
| 기본 텍스트 | `#242521` |
| 보조 텍스트 | `#65665F` |
| 구분선 | `#CCCBC3` |
| 강조색 | `#365B70` |
| 선택 배경 | `#DFE7E9` |

위 표는 핵심 팔레트다. 시안의 세부 보조색과 치수는 첨부 HTML에 보존되어 있다. 제품 적용 시 팔레트 CSS에서 색상값을 관리하고, 테마 디렉토리의 CSS에서 배경·텍스트·강조 등 역할별 토큰에 연결한다.

## 글꼴과 배치

- 문서 제목과 주요 본문 소제목·인용에는 명조체를 사용한다. 시안은 바탕체와 Georgia 등의 시스템 글꼴을 사용한다.
- 본문과 메뉴는 고딕체를 사용한다. 시안은 맑은 고딕과 시스템 sans-serif를 사용한다.
- 왼쪽 문서 탐색, 가운데 문서, 오른쪽 보조 패널의 3단 구성을 시각 기준으로 삼는다.
- 문서 본문을 주변 패널보다 밝게 두고 읽기 영역에 충분한 여백을 확보한다.
- 탭 스트립과 문서 헤더는 서로 다른 행으로 둔다.
- 작은 모서리 반경과 얇은 구분선을 사용하고, 강한 그림자와 장식은 배제한다.

## 적용 범위와 후속 명세

이번 결정은 시각 디자인의 승인 기록이다. 제품 요구사항의 정본은 계속 `docs/spec/`이며, 이 문서는 별도 요구사항 명세나 구현 완료 증거가 아니다.

첨부 시안의 목차·문서 속성·검색 단축키·모바일 배치·예시 데이터는 외관을 설명하는 요소다. 이 시안을 승인했다고 해서 해당 기능이나 Phase 2 범위가 Phase 1 요구사항으로 추가되는 것은 아니다. 실제 기능과 표시 위치는 기존 SRS를 따르며, 변경이 필요하면 SRS에 먼저 반영한다.

승인된 HTML은 라이트 외관을 담으며 원본을 유지한다. 2026-09-16 사용자가 디자인 결정을 Astra에 위임함에 따라 다크 팔레트는 [구현 핸드오프](./newspaper-implementation-handoff.md)의 정확한 색상으로 결정했다(`IR-SHELL-006` AC-2). 결정 승인은 완료됐으며, 비교 시안 작성과 독립 대비·브라우저 검증은 Sol의 후속 작업이다. 그 증거가 확보되기 전 #45를 완료하거나 제품 다크 CSS를 적용하지 않는다. 라이트·다크·시스템 선택 체계와 사용자별 DB 저장 원칙은 유지한다.

초기 승인 기록은 제품 코드·SRS를 변경하지 않았다. 후속 #42 계약 저작에서는 공식 MCP로 `IR-SHELL-006`~`009`, `IR-EDITOR-002`, `IR-AUTH-003`, `IR-WORKSPACE-001`, `IR-PRINCIPAL-001`, `FR-STORAGE-010`을 planned/stable로 추가했다. 구현·검증 완료를 뜻하지 않으며 기존 요구사항 상태와 증거는 보존했다.
