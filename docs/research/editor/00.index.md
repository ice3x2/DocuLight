## 한 줄 결론

> **`kenforthewin/atomic-editor`(MIT)를 vendor 하여 개조한다.**
> 라이브 프리뷰 코어 7종 + 표 WYSIWYG 편집이 확보되며, 한글 IME 와 표는 실동작으로 검증되었다.
> 미구현분(수식 · Mermaid · 소스 모드 · 첨부 · 자동 저장 · 병합 뷰)은 대부분 코어 무수정으로 얹을 수 있다.

## 조사로 뒤집힌 전제

기능 요청서 `02.feature-request-live-preview.md` 작성 시점의 판단 중 **조사로 반증된 항목**입니다.
요구사항 승격 시 반드시 반영해야 합니다.

| 요청서 위치 | 당시 판단 | 조사 결과 |
|---|---|---|
| §1 · §8 | "기성 패키지가 존재하지 않는다" | **반증.** 사용 가능한 구현이 최소 2개 존재 |
| §8 참고 | `codemirror-rich-obsidian` 참고 가능 | **소멸.** npm 미등재 · GitHub 404 |
| §8-1 | 표가 최난제, 가장 먼저 검증 필요 | **해결됨.** `atomic-editor` 에 WYSIWYG 셀 편집 구현 + 실동작 확인 |
| §4.2 · 수용기준 7 | 한글 IME 가 최대 리스크 | **실동작 확인됨** (2026-08-12, 사용자 검증) |
| §8-3 | `atomicRanges` 로 커서 통과 차단 필요 | `atomic-editor` 는 **미사용**. 전제 재검토 필요 |
| §8-6 | React 19 peer 호환 확인 필요 | **해소.** `^18.0.0 \|\| ^19.0.0` |
| §10-3 | 코드블록 펜스 처리 미확정 | `atomic-editor` 는 **커서 밖에서 펜스를 감춤** |
| §4.5 | 뷰포트 범위만 계산 | `atomic-editor` 는 **전체 트리 순회**. 근거 있는 반대 선택 — [02 문서](./02.atomic-editor-analysis.md) 참조 |
