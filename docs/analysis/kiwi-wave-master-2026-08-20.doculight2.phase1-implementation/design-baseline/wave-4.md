# wave-4 — 셸 골격과 노드 조작 — 트리·탭·설정 모달·휴지통

> 설계 발췌. 정본은 `docs/spec/00.decision-log.md` 이며 이 파일은 그 wave 범위의 사본이다.
> 충돌하면 원장이 이긴다.

**목표** — 로그인 후 화면의 골격이 선다 — 좌측 사이드바 3탭·우측 사이드바 3탭·상단 문서 탭 스트립과 2단 문서 헤더·설정 모달. 트리가 wave-2 의 완전 숨김을 실제로 반영해 그리고, 컨텍스트 메뉴에서 만들기·개명·삭제가 되며, 삭제된 것이 휴지통으로 가서 복구되거나 보존 기간 경과 시 자동 영구 삭제된다. 런타임 설정의 단일 저장소가 DB 로 선다.

**요구사항** 24건 · **설계 항목(원장 조항)** 29건
