# wave-6 — 찾기 계열 — 링크·백링크·태그·전역 검색·MCP

> 설계 발췌. 정본은 `docs/spec/00.decision-log.md` 이며 이 파일은 그 wave 범위의 사본이다.
> 충돌하면 원장이 이긴다.

**목표** — 문서를 찾는 세 경로가 모두 선다 — 위키링크 자동완성과 백링크·아웃고잉 링크(워크스페이스 경계를 넘는 인덱스 위에서), 좌측 검색 탭의 텍스트 검색과 우측 태그 탭, 그리고 PAT 로 인증하고 호출자 ACL 로 결과가 갈리는 MCP·벡터검색 표면. 표시 직전 요청자 권한 필터가 이 표면 전량에 동일하게 걸린다.

**요구사항** 18건 · **설계 항목(원장 조항)** 22건

| `R106` | §2.1 UI · 에디터 | 53 | **개정 (2026-08-18) — 우측 사이드바 `태그` 탭은 접근 가능한 전 워크스페이스의 태그 목록과 각 태그의 출현 문서 수**를 보여준다. **집계 원천에 R80 을 적용한다** — 개수만 거르는 것이 아니라 **태그의 등장 자체가 필터를 거치므로**, 요청자가 볼 수 있는 문서에 한 번도 나타나지 않는 태그는 목록에 없다. 범위는 **접근 가능한 전 워크스페이스 통합 목록 + 범위 선택기**다. **개수의 단위는 `출현 문서 수` 이지 `출현 횟수` 가 아니다** — R80 이 문서 단위로 걸리므로 출현 횟수는 이 필터 위에서 정의되지 않는다. **옵시디언 문구(`number of occurrences`)를 그대로 옮기지 않는 것은 의도적이다** |
