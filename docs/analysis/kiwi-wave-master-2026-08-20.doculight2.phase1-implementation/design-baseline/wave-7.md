# wave-7 — 권한·주체 관리 화면과 이동·복사

> 설계 발췌. 정본은 `docs/spec/00.decision-log.md` 이며 이 파일은 그 wave 범위의 사본이다.
> 충돌하면 원장이 이긴다.

**목표** — 관리자가 권한 상태를 관측하고 손볼 수단이 선다 — 공유 모달의 상속 항목 표시와 권한 지정 UI, 접근자 지표 두 종, 유효 권한 시뮬레이션, 상속 끊김 노드 목록과 상속으로 되돌리기, 주체 단위 일괄 회수. 사용자·그룹 관리와 네 단계 오프보딩, PrincipalPicker 공용 컴포넌트가 함께 선다. 이동·복사도 여기서 완성된다 — 두 조작이 접근 가능 인원을 바꾸므로 그 프리뷰가 지표 위에서만 성립한다.

**요구사항** 26건 · **설계 항목(원장 조항)** 37건
