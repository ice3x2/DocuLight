# wave-5 — 본문 표면 — 에디터·자동 저장·버전·충돌·첨부

> 설계 발췌. 정본은 `docs/spec/00.decision-log.md` 이며 이 파일은 그 wave 범위의 사본이다.
> 충돌하면 원장이 이긴다.

**목표** — 본문 영역이 완성된다 — 보기/편집 모드 토글과 라이브 프리뷰, 무버튼 자동 저장, 내용 해시 기반 충돌 감지와 머지 화면, 편집 세션당 1회의 버전 스냅샷과 복원. 같은 본문 슬롯에 비-md 파일이 들어와 이미지는 미리보기·그 외는 다운로드 링크가 되고, 트리 드래그앤드롭과 편집기 붙여넣기 두 경로로 첨부가 `.res` 해시 저장된다.

**요구사항** 35건 · **설계 항목(원장 조항)** 38건
