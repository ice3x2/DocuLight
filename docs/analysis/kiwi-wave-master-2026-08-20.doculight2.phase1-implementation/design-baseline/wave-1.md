# wave-1 — 모노레포 골격과 영속 기반

> 설계 발췌. 정본은 `docs/spec/00.decision-log.md` 이며 이 파일은 그 wave 범위의 사본이다.
> 충돌하면 원장이 이긴다.

**목표** — 저장소에 루트 package.json 과 워크스페이스를 세우고, Express 백엔드 + Vite/React/TS SPA 를 한 Node 프로세스로 띄운다. 파일시스템(docsRoot)과 SQLite 두 저장소를 열고, 모든 노드에 경로 독립적인 랜덤 안정 ID 를 붙이며, 워크스페이스 물리 레이아웃과 사이드카·이름 검증·서빙 거부 규칙을 세운다. 최초 기동 시 기본 워크스페이스가 생긴다.

**요구사항** 24건 · **설계 항목(원장 조항)** 32건
