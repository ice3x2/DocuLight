# Issue #50 TDD chronology audit

This audit distinguishes test chronology from observed failures. A checker being present before product code does not mean every fail-fast assertion was reached by that RED run.

## Evidence integrity

- `red-sidebar-keyboard-raw.txt`, `green-sidebar-keyboard-raw.txt`, `red-surface-retro-raw.txt`, and `red-sidebar-overflow-retro-raw.txt` are command stdout/stderr captured directly with `Tee-Object`.
- `red-vitest.txt` and the first part of `red-playwright.txt` were manually transcribed summaries of tool output. They are not raw stdout and must not be represented as raw evidence.
- The second settings-row entry in `red-playwright.txt` is also a manual transcription. Its observed value was `320.5px`, but the file is not a raw command transcript.
- `green-measurements.json` is machine-written by the Playwright checker and contains the computed geometry used by the final GREEN run.
