## State and focus decisions

Expose real query presentation state from App through AppShell, using the existing ready/loading/error pattern and real refetch callbacks. It is part of IR-SHELL-009 AC-3, not a new data API. Query failure takes precedence over stale success; loading must not be converted to empty. During a scope or active-document transition do not display old-scope/old-document rows as current results. For an active refetch, a loading surface may replace rows while the fixed tag controls remain usable; stale retained data must never masquerade as current success.

| State | Required presentation |
| --- | --- |
| No active document | Link panel neutral instruction `문서를 선택하면 링크를 볼 수 있습니다.`; no retry, no fabricated loading. Global tag index still operates. |
| Loading actual enabled query | Shared LoadingState, specific label (`백링크 불러오는 중`, `아웃고잉 링크 불러오는 중`, `태그 불러오는 중`); active tabpanel `aria-busy=true`. |
| Successful empty | Shared EmptyState: `백링크가 없습니다.`, `아웃고잉 링크가 없습니다.`, or `태그가 없습니다.`; no explanation based on hidden documents. Keep successful tag basis and scope controls. Preserve the named empty list semantics where existing callers/tests rely on them. |
| Query error | Shared ErrorState with panel-specific failure title and safe existing error handling; actual retry only. Do not expose raw internal response payloads or turn permission-denied information into row-level explanations. |
| Disabled/readonly/invalid | Scope has no authored-value validation, so invalid is N/A. No permission-disabled tabs or fabricated disabled links. Unresolved text is noninteractive readable/copyable content. Actual pending retry may use shared disabled treatment if present; do not disable scope changes solely to simplify race handling. |

Keep Radix ArrowLeft/Right and Home/End tab behavior; Tab enters scope then rows in normal DOM order, native select owns keyboard selection, Enter/Space activates buttons. Loading/error replacement must leave focus somewhere useful in the same tabpanel; if a focused retry or row is removed, restore to the active panel/tab without stealing focus after a user deliberately moves elsewhere. Scrolling focused first/middle/last rows must reveal the complete outline. Tag activation leaves focus on its button while left search opens, following current behavior. No text entry is introduced here; IME validation is N/A to these controls, and existing search IME behavior is preserved.
