# GitHub #55 Astra decision independent review

## Verdict

**PASS — Critical 0, High 0, Medium 0, Low 0.**

The decision is consistent with GitHub #55, the approved #54 decision and rereview, FR-EDITOR-007, FR-EDITOR-010, IR-EDITOR-001, and stable IR-EDITOR-002 AC-1 through AC-5. It introduces no unsupported product policy.

## Independent checks

- **Ownership:** #54 retains base typography, reading measure, common semantic integration, source/search/caret/selection, and open-MergeView theme plumbing. #55 owns complex-content styling, Mermaid cache/theme/error behavior, and the IR-EDITOR-002 AC-4 minimum non-color difference cue. #57 retains comparison navigation, resolution actions, layout, and the wider merge/recovery UX. The narrowly authorized cue wiring does not import #57's product behavior into #55.
- **Feasibility and licensing:** the current editor already depends on Shiki 3.23.0, Mermaid 11.16.1, KaTeX 0.16.47, and `@codemirror/merge` 6.12.2. No new dependency is proposed. The relevant installed packages are MIT licensed. Shiki 3.23.0 exposes `createCssVariablesTheme`; with `fontStyle:false` it emits no metric-changing italic/bold/underline settings, and its emitted semantic/ANSI variables match the decision's required mapping. `@codemirror/merge` exposes `Chunk` and `getChunks`, so viewport-aware per-chunk labels can be implemented without altering saved/copied source.
- **Theme correctness:** code is moved off the current hard-coded `github-light` theme to semantic CSS variables; unresolved variables, ANSI variants, unsupported-language fallback, delayed stale output, selection contrast, and byte preservation are explicit gates. Tables, tags, links, quotes, task checkboxes, KaTeX descendants, and generated Mermaid SVG colors consume the approved roles without adding palette values. The accepted #54 checked-glyph repair is preserved.
- **Error and security boundaries:** KaTeX retains its common stylesheet, bundled font geometry, visually hidden MathML, and non-throwing partial-input behavior. Math and Mermaid errors expose exact escaped/selectable author source in read-only as well as editable views, while Mermaid diagnostics exclude stack traces, filesystem paths, detached global graphics, and editable-source affordances. Mermaid keeps `securityLevel:'strict'`, `startOnLoad:false`, suppressed global error rendering, unique IDs, and success/failure temporary-node cleanup.
- **Race and cache safety:** Mermaid render identity includes exact source and resolved palette/font/security configuration; measured size additionally includes available width. Global initialize plus render is serialized, each request captures its configuration, stale generations cannot attach or update size, virtualized destruction releases observers/listeners, and height changes request CodeMirror measurement. Theme reconfiguration is deferred through composition and does not change markdown, selection, history, save state, or EditorView identity.
- **Geometry and interaction:** rendered code, tables, large diagrams, and block math keep local overflow inside padding-owned measured wrappers. The decision expressly tests final-edge reachability, keyboard scrolling, table reveal/event ownership, source round trips, click/`posAtCoords` accuracy, heightmap drift, asynchronous replacement, disclosure expansion, virtualization, IME, and autosave/conflict/body-recovery paths. Tag activation preserves actual AppShell search routing and prevents duplicate activation or Space scrolling.
- **Accessibility and diff cues:** interactive overflow regions receive names and keyboard reach only when needed; focus indicators and contrast are computed in both themes. Invalid content remains readable and source-accessible. Inserted and deleted chunks receive associated visible DOM labels, including pure insertion/deletion and later recomputation, while labels remain absent from clipboard and persisted source.
- **Browser evidence:** the required matrix is 1280×720, 1440×900, and 1920×1080 in light/dark at 100% and genuine 200% (12 environments). The 200% procedure requires isolated persistent Chromium plus an extension calling `chrome.tabs.setZoom(tabId, 2)`, asserts `getZoom===2`, and records pre/post CSS viewport and DPR. CSS zoom, transforms, device-scale substitution, and half-viewport emulation are explicitly rejected. Actual product `DocumentSurface`, common stylesheet, runtime theme, screenshots, computed styles, geometry, focus, long content, and built output are required; demo-only evidence is insufficient. Native Windows Korean IME is correctly distinguished from synthetic/CDP composition.

IR-EDITOR-002 remains planned/stable, so implementation is permitted, but the decision correctly prohibits claiming the whole requirement verified until every separately owned portion has evidence. The decision itself claims no implementation or verification.
